# ApexLab 2.0.0

Первая публичная сборка ApexLab — локальной студии телеметрии для Assetto Corsa Competizione.
Читает логи MoTeC `.ld` напрямую, разбирает круги, показывает ошибки пилота и предлагает правки сета.
Всё считается на твоём компьютере: без интернета, аккаунтов и облака.

## Что внутри

| Раздел | Что делает |
|---|---|
| **Гараж** | все импортированные сессии: трасса, машина, дата, лучший круг, оценка пилота, ошибки. Дубликаты экспорта MoTeC схлопываются, битые логи пропускаются с причиной |
| **Обзор** | оценка пилота, темп, стабильность, торможение, тяга, баланс, плавность; графики скорости/газа/тормоза/передач и карта трассы с курсором |
| **Траектория** | сравнение линии круга с эталоном: карта с подсветкой отклонений, график отклонения по дистанции, разбор проблемных зон по поворотам |
| **Круги** | таблица кругов, чистые и невалидные, теги пита и выезда, выбор круга для разбора |
| **Ошибки** | блокировки колёс, пробуксовки, пробои подвески, перегрев тормозов и движение накатом с привязкой к поворотам |
| **Сет** | разбор JSON-сета ACC и рекомендации «было → стало» под найденные проблемы пилота |
| **Пилоты** | сводный профиль по всем сессиям: радар техники, лучший круг по трассам, средние оценки |
| **Сравнение** | два круга бок о бок: дельта по дистанции, скорости, газ/тормоз, карты траекторий, таблица по поворотам |

Плюс текстовый отчёт по сессии (`Ctrl+E`), командная строка (`Ctrl+K`) и семь тем оформления.

## Оформление

Карбон (по умолчанию), Полночь, Янтарь, Фиалка, светлая День, чёрно-белая Моно и графитовая Графит.
Тема применяется мгновенно, без перезагрузки страницы и перерисовки разбора: графики и карта перекрашиваются на месте.
Переключение — слева внизу, по `Ctrl+Shift+T` или карточками в «Настройках»; выбор запоминается.

## Нативное окно

Окно без системной рамки: своя панель с логотипом, поиском и кнопками. Её можно тянуть мышью, двойной щёлчок разворачивает на весь экран, за края и углы окно тянется как обычное.
Есть булавка «поверх остальных». Размер, положение и тема запоминаются между запусками.
Если в системе нет WebView2, приложение сообщит об этом и откроется в обычном браузере на `http://127.0.0.1:8765/`.

## Установка

1. Скачай `ApexLab-2.0.0-win64.zip` из ассетов ниже.
2. Распакуй **целиком** в любую папку, кроме `Program Files` — приложению нужно писать рядом свои данные. Запускать прямо из архива нельзя: Windows не даст сохранить библиотеку.
3. Двойной щёлчок по `ApexLab/ApexLab.exe`.

Python, numpy и pywebview ставить не нужно — всё внутри exe.

При первом запуске приложение само ищет папку ACC в «Документах». Если не нашло — «Настройки» → указать пути к MoTeC и Setups → «Импорт».
Рядом с exe появится папка `data` — библиотека, кэш разбора и журнал `apexlab.log`. Её можно удалить, приложение соберёт всё заново из логов. Исходные логи и сеты приложение только читает.

> **Windows SmartScreen.** Сборка не подписана платным сертификатом, поэтому система может предупредить, что издатель неизвестен: «Подробнее» → «Выполнить всё равно».

## Требования

- Windows 10 или 11, 64 бита.
- Microsoft Edge WebView2 Runtime — уже есть в Windows 11 и в актуальном Edge. Без него приложение работает в браузере.
- Assetto Corsa Competizione с включённой записью телеметрии MoTeC.

## Единицы в сете

ACC пишет setup в кликах, а гараж показывает физику. ApexLab пересчитывает клики в то, что видно в игре: давление в psi (холодное), развал и схождение в градусах, пружины в Н/мм, клиренс в мм, отбойник в Н, баланс тормозов в %, предварительная нагрузка в Нм.
Стабилизаторы, амортизаторы, крыло и воздуховоды остаются в кликах — в игре они тоже в кликах.
Для машин вне таблицы пересчёта (GT4, M2 CS Racing, моды) над сетом появляется предупреждение, а «кликовые» параметры остаются в кликах.

## Как считается сравнение траекторий

Траектория восстанавливается по каналу рыскания `ROTY` и скорости, затем пересэмплируется с шагом 5 м по дистанции. Отклонение — расстояние от твоей линии до линии эталона по нормали к эталонной траектории. Медленный дрейф интегрирования рыскания снимается полиномом и скользящим средним, поэтому метры показывают локальные различия линии в поворотах, а не абсолютные координаты.

Эталон по умолчанию — самый быстрый чистый круг на этой трассе в любой сессии; его можно сменить в списке над картой.
Круги разной длины (выезд из боксов, пит, неполный круг) по дистанции не сравниваются, а на невалидном круге сравнение отключается — иначе разбор был бы ложным.

## Известные ограничения

- Приложение не подписано — SmartScreen предупреждает при первом запуске.
- Машины вне таблицы пересчёта сета показываются в кликах.
- Если в логе нет `ROTY`, траекторию восстановить нельзя — вкладка покажет причину.
- ACC не пишет имя пилота в лог, поэтому сессии переименовываются вручную.

Исходники, дорожная карта и инструкция по сборке — в репозитории. Бета-канал с экспериментами собирается отдельно: `python apexlab\tools\build_exe.py beta`.
