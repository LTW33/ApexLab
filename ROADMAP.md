# ApexLab — дорожная карта

Два канала. Работаем в двух отдельных сессиях, чтобы полировка не смешивалась с экспериментами.

| | Релиз | Бета |
|---|---|---|
| Цель | довести существующее до идеала | вводить новые идеи |
| Что можно | баги, точность данных, вёрстка, скорость, тексты | новые экраны, метрики, автоматизация |
| Что нельзя | новые функции, смена форматов данных | ломать релизные сценарии |
| Флаг | выключен | `html.beta` (бейдж BETA в заголовке) |
| Сборка | `python tools\build_exe.py` | `python tools\build_exe.py beta` |
| Артефакт | `release\ApexLab-2.0.0-win64.zip` | `release\beta\ApexLab-2.1.0-beta-win64.zip` |

## Правила каналов

- Новое поведение по умолчанию скрыто: обёртка `if (channel.isBeta()) { ... }` или CSS `html.beta .selector`.
- Переключатель для пользователя: «Настройки» → «Канал» → «Эксперименты»; в бете включён по умолчанию, `?beta=1` / `?beta=0` — принудительно.
- Релиз собирается только из проверенного кода. Если фича созрела — переносим её из-под флага в релиз отдельной задачей и проверяем заново.
- Данные: бета может менять схему кэша — тогда поднимаем `VERSION` в `apexlab/session.py`, чтобы релизный кэш не портился.
- Каждая сессия начинается с этого файла и заканчивается обновлением своего раздела.
