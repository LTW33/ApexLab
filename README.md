# ApexLab

Локальная студия телеметрии Assetto Corsa Competizione: читает MoTeC `.ld` напрямую, разбирает круги, показывает ошибки пилота и предлагает изменения сета. Всё работает на твоём компьютере, без интернета и аккаунтов.

## Скачать

Готовая сборка для Windows: **[ApexLab 2.0.0](https://github.com/LTW33/ApexLab/releases/latest)** — `ApexLab-2.0.0-win64.zip`. Распакуй архив целиком в любую папку, кроме `Program Files`, и запусти `ApexLab\ApexLab.exe`. Python и библиотеки ставить не нужно: всё внутри.

## Запуск

1. Установи Python 3.11+ (при установке отметь «Add python.exe to PATH»).
2. Дважды щёлкни `run.bat` в этой папке.
3. Откроется отдельное окно ApexLab — без браузера и вкладок.

`run.bat` сам поставит `numpy` и `pywebview`, если их нет. Окно консоли на время работы — это локальный сервер: закрой его, чтобы остановить приложение. Размер, положение окна и выбранная тема запоминаются в `apexlab\data\ui.json`.

Окно у приложения своё, без системной рамки: сверху тонкая панель с логотипом, поиском и кнопками. Её можно тянуть мышью, двойной щёлчок разворачивает на весь экран, за края и углы окно тянется как обычное. Кнопка с булавкой оставляет окно поверх остальных, крестик закрывает приложение. Свёрнутое окно восстанавливается из панели задач.

Если в системе нет компонента WebView2 (Microsoft Edge WebView2 Runtime), приложение сообщит об этом и откроется в обычном браузере на `http://127.0.0.1:8765/`. В Windows 11 и в актуальном Edge компонент уже есть.

## Оформление

Семь тем, переключаются слева внизу, по `Ctrl+Shift+T` или карточками в «Настройках»:

- **Карбон** — ночной лайм, тема по умолчанию;
- **Полночь** — глубокий синий с циановым акцентом;
- **Янтарь** — тёплый закат;
- **Фиалка** — ночной фиолет;
- **День** — светлая тема с синим акцентом;
- **Моно** — строгая чёрно-белая, без цветных акцентов;
- **Графит** — тёмно-серый металл с серебристыми деталями.

Тема применяется мгновенно, без перезагрузки страницы и перерисовки разбора: графики и карта перекрашиваются на месте, скоростная шкала в «Моно» и «Графите» становится серой. Выбор сохраняется в браузерном хранилище и в `ui.json`; оформление нативного окна подстраивается под тему.

## Горячие клавиши

- `Ctrl+K` — командная строка: поиск сессий, трасс, пилотов и разделов, стрелки и `Enter`;
- `Ctrl+Shift+T` — следующая тема;
- `Ctrl+B` — свернуть или развернуть боковую панель (состояние запоминается);
- `Ctrl+E` — сохранить текстовый отчёт о сессии;
- `Ctrl+P` — печать текущего экрана;
- `Alt+1…Alt+5` — вкладки внутри сессии;
- `F1` — настройки и список горячих клавиш.

## Отчёт

Кнопка «Отчёт» в шапке сессии (или `Ctrl+E`) собирает plain-text отчёт: трасса, машина, дата и лог, результаты и стабильность, разбивка оценки пилота, ошибки с поворотами, потери по поворотам, давления, температуры шин и тормозов, рекомендации по сету. В нативном окне открывается системный диалог сохранения, в браузере файл просто скачивается. Имя файла — `ApexLab_<трасса>_<дата>.txt`.

## Как поделиться

Готовые сборки лежат в [Releases](https://github.com/LTW33/ApexLab/releases): `ApexLab-2.0.0-win64.zip` (exe + короткая инструкция) и отдельный `ApexLab.exe`. Python, numpy и pywebview получателю не нужны — всё внутри, достаточно ссылки на релиз.

Собрать заново после правок:

```
python -m pip install pyinstaller
python apexlab\tools\build_exe.py
```

Скрипт рисует иконку, собирает `ApexLab.exe` (без консольного окна, с иконкой и темами) и пакует zip. Личные логи, настройки и кэш в сборку не попадают: у получателя приложение стартует с пустой библиотекой, само ищет папку ACC и складывает данные в `data` рядом с exe.

Приложение не подписано, поэтому Windows SmartScreen может предупредить: «Подробнее» → «Выполнить всё равно». Запускать нужно из распакованной папки, а не прямо из архива — иначе некуда сохранить библиотеку.

## Два канала: релиз и бета

Разработка разделена, чтобы полировка не смешивалась с экспериментами.

- **Релиз** — только исправления и доводка существующего. Сборка: `python apexlab\tools\build_exe.py` → `release\ApexLab-2.0.0-win64.zip`.
- **Бета** — новые идеи. Сборка: `python apexlab\tools\build_exe.py beta` → `release\beta\ApexLab-2.1.0-beta-win64.zip`.

Новые функции по умолчанию спрятаны: их включает флаг канала. В бете он включён сразу (бейдж `BETA` в заголовке), в релизе — только вручную: «Настройки» → «Канал» → «Эксперименты». Принудительно: `?beta=1` или `?beta=0` в адресе. Для запуска из исходников — `run.bat beta`.

Список задач по каналам — в `ROADMAP.md`: раздел «Релиз» только про полировку, раздел «Бета» — идеи. Релиз собирается из проверенного кода, поэтому бета его не ломает.

Состояние канала хранится в браузере (`localStorage`, ключ `apex.channel`), сборка задаёт значение по умолчанию маркером `beta.flag` внутри exe.

## Что внутри

**Гараж** — все импортированные сессии: трасса, машина, дата, лучший круг, оценка пилота, количество ошибок. Дубликаты экспорта MoTeC схлопываются автоматически, битые логи пропускаются с причиной.

**Сессия** — пять вкладок:

- **Обзор** — оценка пилота, темп, стабильность, торможение, тяга, баланс, плавность; графики скорости/газа/тормоза/передач и карта трассы с курсором.
- **Траектория** — сравнение линии выбранного круга с эталоном: карта с подсветкой отклонений, график отклонения по дистанции и разбор проблемных зон по поворотам. Для каждой зоны объясняется фаза (вход/апекс/выход), сторона (внутрь/наружу), метрики (скорость, моменты торможения и открытия газа, руль, потеря времени) и что делать.
- **Круги** — таблица кругов, чистые/невалидные, теги пита и выезда, выбор круга для разбора.
- **Ошибки** — блокировки колёс, пробуксовки, пробои подвески, перегрев тормозов и движение накатом с привязкой к поворотам.
- **Сет** — разбор JSON-сета ACC и рекомендации «было → стало» под найденные проблемы пилота. Если сетов не видно (другая папка, сеты с другого ПК, ACC их не сохранил), жми «Импорт сета» на вкладке «Сет» или перетащи `.json` прямо на панель — файл скопируется в библиотеку ApexLab и сразу подставится в рекомендации.

### В каких единицах показан сет

ACC хранит setup JSON в кликах ползунков, а в гараже показывает физические значения. ApexLab пересчитывает клики в то, что ты видишь в игре, по таблицам конкретной машины:

- давление — psi, холодное, как в гараже (`47` → `25.0 psi`);
- развал — градусы из `staticCamber`, схождение — градусы на колесо, кастор — градусы;
- пружины — Н/мм, клиренс — мм, отбойник — Н, баланс тормозов — %, предварительная нагрузка дифа — Нм;
- стабилизаторы, амортизаторы, крыло, воздуховоды, диапазон отбойника — клики (в игре они тоже в кликах);
- ECU, топливо, колодки, комплект шин — как в файле/игре.

Для машин, которых нет в таблице (GT4, M2 CS Racing, моды), давление, схождение, кастор, пружины, клиренс и баланс тормозов остаются в кликах — над сетом появляется предупреждение. Общеигровые величины (развал, топливо, электроника, колодки) пересчитываются всегда.

**Пилоты** — сводный профиль по всем сессиям: радар техники, лучший круг по трассам, средние оценки. ACC не пишет имя пилота в лог, поэтому сессии можно переименовать вручную.

**Сравнение** — два круга на одной трассе бок о бок: дельта по дистанции, скорости, газ/тормоз, карты траекторий и таблица по поворотам.

**Настройки** — папки ACC, статистика библиотеки, пересканирование логов, импорт, семь тем карточками и список горячих клавиш.

## Как считается сравнение траекторий

Траектория восстанавливается по каналу рыскания `ROTY` и скорости, затем пересэмплируется с шагом 5 м по дистанции. Отклонение — расстояние от твоей линии до линии эталона по нормали к эталонной траектории. Медленный дрейф интегрирования рыскания снимается полиномом и скользящим средним, поэтому метры показывают локальные различия линии в поворотах, а не абсолютные координаты.

Эталон по умолчанию — самый быстрый чистый круг на этой трассе, в любой сессии. Его можно сменить в списке над картой: тогда сравнение пересчитается, а ссылка сохранит выбор.

Ограничения, о которых приложение предупреждает само:

- если в логе нет `ROTY`, траекторию восстановить нельзя — вкладка покажет причину;
- круги разной длины (выезд из боксов, пита, неполный круг) не сравниваются по дистанции;
- на невалидном круге сравнение отключается: выезд из боксов и пита меняют линию, разбор будет ложным.

## Где лежат данные

- Логи: `Документы\Assetto Corsa Competizione\MoTeC` (`.ld`).
- Сеты: `Документы\Assetto Corsa Competizione\Setups` (`.json`).
- Отчёты: сохраняются туда, куда укажешь в диалоге (или в «Загрузки» браузера).
- Импортированные вручную сеты: `data\setups` рядом с приложением (`apexlab\data\setups` в исходниках). Они подмешиваются к сетам ACC и помечаются в списке как «импорт».
- Кэш разбора: `apexlab\data\cache`.
- Библиотека и настройки: `apexlab\data\library.json`.
- Оформление и геометрия окна: `apexlab\data\ui.json`, журнал запуска — `apexlab\data\apexlab.log`.

Исходные логи и сеты приложение только читает. Удалить кэш можно в «Настройках» — сессии пересоберутся при следующем импорте. Папку `data\setups` удалять можно: это только копии, оригиналы в ACC остаются на месте.

## Если что-то не работает

- **Браузер не открылся** — зайди вручную на `http://127.0.0.1:8765/`.
- **Окно не открылось, приложение ушло в браузер** — нет WebView2; поставь «Microsoft Edge WebView2 Runtime» или пользуйся браузерной версией. Причина записана в `apexlab\data\apexlab.log`.
- **Порт занят** — закрой старое окно сервера; порт выбирается автоматически.
- **«Нужен numpy»** — выполни `python -m pip install numpy`.
- **Сессия без чистых кругов** — оценка помечается как предварительная: в логе есть пита, выезд или контакт.
- **Сеты не найдены** — проверь путь в «Настройках»; если папки нет под рукой, импортируй `.json` на вкладке «Сет». Кнопка «Импорт сета» и перетаскивание файла работают и в собранном `ApexLab.exe`.
- **«В файле нет basicSetup / advancedSetup»** — это не сет ACC (например, экспорт другого симулятора или обычный JSON).
